# 🚀 دليل تشغيل واستضافة مشروع وحدة بلدي على سيرفر العمل (Ubuntu)

هذا الدليل يوضح لزميلك في العمل بالخطوات كيفية تشغيل الموقع وقاعدة البيانات على سيرفر **Ubuntu** عبر الشبكة الداخلية أو الـ **VPN** بكل سهولة.

---

## 🔒 1. إعدادات الخصوصية والأمان (الحماية من محركات البحث)
* تم إضافة ملف `robots.txt` لمنع أي زحف أو أرشفة من محركات البحث (Google / Bing وغيرها).
* تم تضمين وسم الحماية `noindex, nofollow, noarchive` برمجياً داخل كود الموقع لمنع فهرسته حتى لو تم ربطه بنطاق عام.
* بما أن السيرفر يعمل داخل **شبكة محلية (Local IP / VPN)**، فلن تتمكن محركات البحث من الوصول إليه نهائياً.

---

## 🛠️ 2. المتطلبات في سيرفر Ubuntu
تأكد من تثبيت **Docker** و **Docker Compose** في السيرفر عبر الأوامر التالية (إذا لم تكن مثبتة):
```bash
sudo apt update
sudo apt install -y docker.io docker-compose
sudo systemctl enable --now docker
```

---

## 📦 3. خطوات النقل والتشغيل (بأمر واحد)

### الخطوة الأولى: نسخ ملفات المشروع إلى السيرفر
يمكن سحب المشروع عبر Git أو نسخه إلى السيرفر:
```bash
git clone https://github.com/muhammedalrubaish/ticketsdaem.git
cd ticketsdaem
```

### الخطوة الثانية: تشغيل النظام بالكامل
قم بتشغيل الأمر التالي:
```bash
docker-compose up -d --build
```
> ⚡ **ماذا سيحدث تلقائياً؟**
> 1. سيتم تشغيل قاعدة بيانات **PostgreSQL 16**.
> 2. سيتم استيراد كافة البيانات السابقة (4,968 بلاغ والتعاميم) تلقائياً عبر ملف `import_to_postgres.sql`.
> 3. سيتم بناء وتشغيل تطبيق **Next.js** على المنفذ `3000`.

---

## 🌐 4. الدخول على الموقع عبر الشبكة المحلية / VPN

بعد تشغيل السيرفر، يمكن للموظفين الدخول للموقع عبر المتصفح باستخدام عنوان IP الداخلي للسيرفر:
```text
http://<SERVER_IP>:3000
```
*(مثال: `http://192.168.1.100:3000` أو عبر الـ IP المعين للسيرفر في شبكة الـ VPN).*

---

## ⚙️ 5. أوامر الإدارة والصيانة المفيدة

* **عرض حالة الحاويات وسجل التشغيل:**
  ```bash
  docker-compose ps
  docker-compose logs -f web
  ```

* **إيقاف النظام:**
  ```bash
  docker-compose down
  ```

* **إعادة تشغيل وتحديث النظام بعد أي تعديل كود:**
  ```bash
  git pull origin main
  docker-compose up -d --build
  ```

* **استيراد وتحديث قاعدة البيانات بالكامل (إن كانت الحاوية تعمل مسبقاً):**
  ```bash
  docker exec -i balady-db psql -U postgres -d balady_db < ./نسخ_احتياطية_وأرشيف/supabase_backup_latest/import_to_postgres.sql
  ```
